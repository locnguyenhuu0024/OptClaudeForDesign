# Visual art direction

Inspect the user's design references and the repository's actual typography, tokens and components.
Prefer the existing brand language; don't interpret 'modern' as one universal aesthetic.

1. State the visual intent in 1–2 sentences (audience, tone, information priority).
2. Set a deliberate composition: content hierarchy, grid, whitespace rhythm, responsive grouping, emphasis and primary action.
3. Specify typography hierarchy, actual existing font choices, spacing scale, token-based color/surface treatment and states.
4. Offer competing visual concepts only if requested; otherwise choose one coherent direction.
5. Check legibility, hierarchy, contrast constraints and real content length; avoid placeholder-only design acceptance.
6. Make visual feedback actionable: component/region, observed issue, proposed adjustment, why it improves clarity.

**Anti-patterns:** decorative gradients by default, too many card containers, arbitrary shadows, inconsistent radii, microtext, one-size-fits-all SaaS templates, image assets not owned/approved.
**Output:** concise visual contract and targeted implementation notes.
**Boundary:** Do not modify source unless task explicitly assigns you as the single writer.
